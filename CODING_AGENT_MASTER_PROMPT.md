## Correctness and scientific integrity rules
No silent sample exclusions, answer-changes after edits, mismatched prompts, train/dev/confirmatory leaks, quantization mixtures, invented references, imaginary official code, fake human reviews, or picking flattering images. Scoring probability conditional on A/B/C/D is not naturally calibrated correctness probability. A region intervention shows model sensitivity, not identified causal semantic evidence dependence. Record failure categories: unremoved evidence, edit artifacts, context erasure, sham damage, inpainting hallucinations, ambiguous region annotations, language-prior answers, and missed GPU budget.
Tests must cover option token scoring, numerical logits, box geometry, masks, semantic validity flags, image-disjoint split hashing, cache keys, r+ vs r- pairing, model version pinning, bootstrap shared-image resampling and absence of test-set tuning.

Update reports/STATUS.md after each gate; every claimed number must come from an actual run record. Version every deviation. Never repeatedly redesign after looking at confirmatory outcomes to chase significance.
