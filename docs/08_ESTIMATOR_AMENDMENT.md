Let L_a(x)=logit(p(a|x, fixed four choices)), with [1e-6,1-1e-6] clipping counted. The answer anchor a is either the fixed reference answer (ORACLE_DIAGNOSTIC) or the frozen model's unedited argmax (PREDICTED_ANSWER_DIAGNOSTIC); never update a after editing. Candidate-source information is a separate axis: annotation-selected pairs are always oracle-region diagnostics even with a predicted-answer anchor. Only fixed-grid candidates plus the predicted anchor constitute NO_ORACLE_DIAGNOSTIC, and even that is not validated deployment reliability.

D_o(r)=L_a(clean)-L_a(remove_o(r)); H_o(r)=L_a(clean)-L_a(sham_o(r)); d_o(r)=D_o(r)-H_o(r)=L_a(sham)-L_a(remove). Median aggregation M(d)=median_o d_o; V(d)=1.4826 median_o |d_o-M(d)|.

Three fixed exploratory estimators: S1(r)=median d_o(r); S2(r)=median d_o(r)-0.5 V(d(r)); S3(r)=median[d_o(r)-d_o(c(r))]-0.5 V(d(r)-d(c(r))). The coefficient remains 0.5; other original grid values are labeled descriptive ablations, not a search for significance. Baselines include individual raw operators, raw mean/median, sham mean, independent-control mean/median and removal-only control adjustment.

The mutual-control construction is prohibited for S3: z(r+)=-z(r-), equal dispersions, and S(r+)-S(r-)=2 median z, independent of lambda. Under any linear aggregation a shared image-wide additive control also cancels from the pair contrast. A common operator-specific control can change a median ranking through operator-order changes; it does not automatically provide region-specific evidence. Candidate-specific independent controls avoid the forced antisymmetry, but can introduce their own variance and semantic contamination.

Independent control sampler accepts image dimensions, candidate geometry and a fixed image/coordinate seed. It never receives relevance flags, gold answer, expression, annotation identities, model probabilities or sensitivity. It proposes equal-width/height translated rectangles, rejecting overlap with that candidate only. It does not reject overlap with the evaluation negative/positive based on hidden labels. Failure to find a nonoverlapping control is an explicit ineligibility; outcome-dependent replacement is forbidden. Control relevance is unknown until external semantic audit. Post-hoc overlaps with other annotated objects are reported, not silently filtered.

Exploratory pair references: positive is the frozen annotated target; the corrected GQA cohort requires exactly one explicitly referenced object. Negative is a nonreferenced annotated box selected by minimum area mismatch, then L1 coordinate-distance tie break, before outcomes. Eligibility permits <=50% area mismatch; <=15% is a reported stratum, not an outcome-dependent filter. Internal edit indices store positive first and negative second; these indices are never shown to the model, whose original answer presentation stays fixed. Human review packet order is randomized. No relevance label is passed to numerical scorers.

Edits use canonical RGB capped at 768px, matching the VLM cap, with no artificial source upscaling. All variants share the same canonical resize and overlay. Treatment mask adds a fixed 8px halo around the core box. Occlusion, strong Gaussian blur (sigma 24) and official LaMa act on the same expanded mask. Shams restore the exact original core into the corresponding treatment, leaving the halo artifact. This preserves core pixels but does not guarantee the semantics of contextual relations or match interior removal artifacts. Identity/whole-image pixels remain independently checked. LaMa is official source and checkpoint in isolated CPU process; no diffusion substitute.
