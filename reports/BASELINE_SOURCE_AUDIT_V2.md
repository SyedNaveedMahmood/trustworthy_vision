# Closest-paper source audit

Official sources were checked before choosing adapters. PDFs, SHA-256 and extracted text are retained locally; small hashes are in `reports/evidence/v2/paper_sources.json`.

- [EVICT, CVPR workshop paper](https://openaccess.thecvf.com/content/CVPR2026W/GRAIL-V/papers/Kotte_EVICT_Evidence-Sufficiency_Verification_via_Counterfactual_Dropout_for_Visually-Grounded_Selective_Question_CVPRW_2026_paper.pdf): equations 2–3 use normalized answer-token Jaccard change, with a 0.7 threshold, after RGB [128,128,128] masking. The official paper page and targeted GitHub search did not identify released author code in this audit; absence from this search is not proof none exists. We implement these equations with tests, and run the exact gray fill on the unexpanded region. Original and perturbed fixed-choice predictions are mapped to semantic option text before Jaccard, never compared merely as answer letters. **PAPER_EQUATION_ADAPTER**, not a full EVICT reproduction: annotated boxes replace cited boxes, forced choices replace free generation, and no isotonic selective-answering calibrator is trained. The 2×2 fill/halo factorial separates color from mask-support changes. The paper's selective-QA metrics are not directly comparable to region ranking.
- [CSGR paper](https://arxiv.org/abs/2609.13228): the inspected PDF promises future code/data release. Its pipeline uses segmentation proposals, prompted Stable Diffusion 2 interventions, self-consistency confidence, iterative search and judge-mask intersection. A single LaMa likelihood drop would omit those central elements. We therefore report our LaMa baseline as a raw sensitivity baseline and do **not** name it CSGR or claim an official reproduction. A full controlled CSGR comparison is unfinished and would require separate pins, sampling/cost decisions and protocol work.
- CoEV repository checked through GitHub: source inventory from v1 records it; the recheck still exposed README rather than an executable compatible implementation. No fabricated official baseline is included.

These limitations remain explicit even if a simple adapter performs well. Official LaMa source and the official three VLM checkpoints are reused directly; their verified revisions are separate from paper baseline reproduction status.
